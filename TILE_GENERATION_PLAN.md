# Native 1920x1080 tile generation

The local SD server is designed to keep the final output at exactly 1920x1080 while reducing peak GPU memory by generating the scene as 8 tiles (4 columns x 2 rows) and stitching them into one PNG.

Important: this is not a fallback to a smaller final image. Each completed scene must be exactly 1920x1080. Existing narration WAV files are not regenerated by `generate_images_only.py`.
